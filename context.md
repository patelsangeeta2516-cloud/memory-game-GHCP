# Repository Context

## What this repo does
This repository contains a browser-based Memory (Concentration) card game built with plain HTML, CSS, and JavaScript. Players flip cards to find matching pairs, track their score using moves and time, and can play on different board sizes such as 4x4 and 6x6.

The project is designed to be lightweight and dependency-free, with responsive layout, accessibility improvements, and local high-score persistence using browser storage.

## What the project stands for
The codebase itself is named `memory-game-GHCP`, but there is no formal definition of the `GHCP` acronym anywhere in the app or README. Based on the repository contents, it appears to be a project or environment label rather than a meaningful acronym for the game itself.
